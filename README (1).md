# Smart-Search Floor Manager

Empty-room finder for SRM Tiruchirappalli (Odd Sem 2026-27, 9 timetables).

- Floor-by-floor free/occupied grid
- AI-style room search (natural language) – falls back to a keyword parser
- 3D building map with live countdown to the next class
- "Call the Squad" – pre-filled WhatsApp invite

Single file app: open `index.html` or host with GitHub Pages.
Room AC/capacity/type data is assumed – edit the `META` object in `index.html`.
